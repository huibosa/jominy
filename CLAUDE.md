# Jominy Project — AGENTS.md

## Project Overview

Jominy end-quench test data cleaning and hardness prediction for steel hardenability modeling. The project processes raw lab data from steel Jominy tests, cleans it into a ML-ready long-format dataset, and will eventually train models to predict hardness from chemical composition.

**Domain**: Metallurgy / Steel hardenability
**J9 / J15**: Hardness measured at 9 mm and 15 mm from the quenched end of a standard Jominy specimen (Rockwell HRC). Physical constraint: J9 ≥ J15 (hardness decreases with distance).
**炉号 (Heat number)**: Specimen identifier. P-pattern heats (`P\d{8}`) may have suffixed variants (`-H` head, `-Z` middle) representing different physical specimens from the same heat.

### Known Data Quality Issues

- **数据汇总 has mixed types**: Element columns are `object` dtype due to a duplicate header row and possibly other string values. Must use `pd.to_numeric(errors='coerce')` when loading.
- **106 non-standard 炉号**: Suffixed (`-H`, `-Z`, `-999`), internal codes (`423V2-*`), bare numbers (`1`–`4`, `20240516`), grade name (`20CrMnTiH`).
- **~75% null hardness**: Most rows have chemistry only, no Jominy test result.
- **High null trace elements**: Al ~50%, B ~58%, Ti ~30%, W ~24% in the full dataset.
- **143 inconsistent heats**: Same 炉号 with different element readings across rows.
- **Multiple hardness measurements**: Same 炉号 can have 2–6 repeated J9/J15 values.
- **File hierarchy**: 数据汇总 is a strict superset. All other files' heats are contained within it. No need to read multiple files.

## Key Domain Constraints

- **Monotonicity**: J9 ≥ J15 must always hold. The cleaned dataset has zero violations.
- **base_heat_id for splitting**: All specimens sharing a base heat must stay in the same train/test fold to prevent leakage.
- **Suffixed 炉号 = separate specimens**: `-H` (head) and `-Z` (middle) are physically different test pieces with potentially different chemistry. Never median-blend them.
- **Selection bias**: Labeled data has much lower C (0.198 vs 0.457) and higher Cr (1.13 vs 0.41) than the unlabeled pool. Models will be biased toward the labeled distribution.
- **Small training set**: 566 specimens, 18 features. High overfitting risk — use strong regularization.
