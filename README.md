# Jominy

End-quench (Jominy) test data cleaning and hardness prediction for steel hardenability.

This project ingests raw lab data from steel Jominy tests, cleans it into a ML-ready long-format dataset, and trains models to predict Rockwell hardness at fixed distances from the quenched end (J9, J15) from chemical composition.

**Domain.** J9 / J15 are the Rockwell C hardness values measured 9 mm and 15 mm from the quenched end of a standard Jominy specimen. They quantify hardenability — the steel's ability to form martensite at depth. Physical constraint: J9 ≥ J15.

## Best model

Convex blend of XGBoost and PLS, validated by 5-fold `GroupKFold` on `base_heat_id`:

```python
xgb = XGBRegressor(n_estimators=1500, max_depth=3, learning_rate=0.005,
                   subsample=0.55, colsample_bytree=0.5, reg_lambda=2.0,
                   random_state=42)
pls = PLSRegression(n_components=3, scale=False)

y_pred = 0.70 * xgb_pred + 0.30 * pls_pred
```

| Target | MAE | RMSE | R² |
|--------|----:|-----:|---:|
| J9     | **1.71** | 2.22 | 0.48 |
| delta  | 1.09 | 1.44 | ~0  |

J9 prediction quality (cross-validated, n = 566):

- 65% of predictions within ±2 HRC, 84% within ±3 HRC
- Median |error| = 1.40 HRC
- Bias ≈ 0 in the middle of the distribution; at the extremes (J9 < 32 or J9 ≥ 41) the model regresses to the mean by ±3 HRC. Many tail specimens have indistinguishable chemistry but very different hardness — irreducible with the current feature set.

R²(delta) ≈ 0 confirms the J9–J15 spread cannot be predicted from chemistry alone on this dataset.

## Data

### Raw (`data/`)

Twelve `.xlsx` files from the lab. All share the same 15-column schema (`炉号` heat ID, 13 element columns, J9 *or* J15). Two master files (`J9-数据汇总.xlsx`, `J15-数据汇总.xlsx`) are strict supersets of the rest.

Known issues — duplicate header rows in master files (mixed `object` dtypes), 75% missing hardness values, 106 non-standard 炉号, ~58% missing B / ~50% missing Al.

See [CLAUDE.md](CLAUDE.md) for the full data dictionary and quality notes.

### Cleaned (`data/`)

Generated by `scripts/clean_jominy.py`:

| File | Rows | Description |
|------|-----:|-------------|
| `jominy_cleaned.parquet` / `.csv` | 1,057 | Long-format training data (one row per specimen × distance) |
| `jominy_chemistry_only.parquet` / `.csv` | 3,498 | Specimens without hardness — for unsupervised analysis |
| `cleaning_report.json` | – | Step-by-step audit log |
| `quarantine.json` | 28 | Rows excluded with reason |

### Modeling tables (`data/modeling/`)

Generated by `scripts/build_modeling_tables.py`:

- `j9_dataset.parquet` (566 rows) — specimens with measured J9
- `delta_dataset.parquet` (491 rows) — specimens with both J9 and J15
- `specimen_table.parquet` — wide-format master

## Pipeline

```
data/*.xlsx
   └─ scripts/clean_jominy.py
        └─ data/jominy_cleaned.{parquet,csv} + jominy_chemistry_only.{parquet,csv}
             └─ scripts/build_modeling_tables.py
                  └─ data/modeling/{j9,delta,specimen}_*.parquet
                       ├─ scripts/run_baselines.py        ← baseline reference (Ridge, mean)
                       ├─ scripts/run_model_comparison.py ← Task-5 challenger comparison
                       ├─ scripts/run_robustness_checks.py
                       ├─ scripts/select_final_model.py
                       └─ scripts/model_experiments*.py   ← this work (rounds 1-7)
```

The `scripts/model_experiments*.py` runners append every candidate to `HISTORY.md`. The current production export still ships the fixed-v1 PLS / Ridge from `select_final_model.py`; promoting the blend requires updating that script and the J15 reconstruction in `assemble_pair_predictions`.

## Reproduce

Requirements: Python 3.12, [`uv`](https://docs.astral.sh/uv/), one-shot installs handled by `uv run --with`.

```bash
# 1. Clean raw data → long-format datasets
uv run --with pandas,openpyxl,pyarrow scripts/clean_jominy.py

# 2. Build modeling tables
uv run --with pandas,pyarrow scripts/build_modeling_tables.py

# 3. Original baseline / comparison / final export
uv run --with pandas,pyarrow,scikit-learn scripts/run_baselines.py
uv run --with pandas,pyarrow,scikit-learn scripts/run_model_comparison.py
uv run --with pandas,pyarrow,scikit-learn scripts/select_final_model.py

# 4. Iterative model search (logs each candidate to HISTORY.md)
uv run --with pandas,pyarrow,scikit-learn,xgboost,lightgbm \
    scripts/model_experiments.py --quick
uv run --with pandas,pyarrow,scikit-learn,xgboost \
    scripts/model_experiments_round{2,3,4,5,7}.py
uv run --with pandas,pyarrow,scikit-learn,xgboost,lightgbm \
    scripts/model_experiments_round6.py

# 5. Inspect winner OOF predictions
uv run --with pandas,pyarrow,scikit-learn,xgboost \
    scripts/inspect_winner.py
```
